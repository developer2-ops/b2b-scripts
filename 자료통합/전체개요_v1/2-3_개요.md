# 2-3. USP 짜는 법

**촬영 담당:** 권기동

상태: 사용자 검토용 내용 개요 v1. 대본·최종 승인 전.

## 강의의 역할

고객이 구분할 선택 이유를 정하고 증명할 근거를 붙인다.

## 반드시 다룰 내용과 개념 관계

1. 고객이 대안 대신 우리 상품을 선택할 이유를 한 문장으로 정리한다.
2. 원하는 결과·신뢰 근거·소요 시간·노력의 차이에서 실제 차별점을 찾는다.
3. 표현한 약속마다 증명 자료와 적용 조건을 대조해 과장된 주장을 줄인다.

위 항목들은 이번 강의에서 확보할 내용의 범위다. 각 항목의 개념·이유·조건을 충분히 설명하고 서로의 관계를 드러내야 한다. 실제 대사 순서는 후속 논리 설계에서 정하며, 모든 강의를 동일한 도입·문제·해결 공식에 맞추지 않는다.

## 수강생이 남길 결과물

USP·증거표

## 다룰 범위와 넘길 범위

USP를 멋있는 슬로건만 만드는 작업으로 끝내지 않는다.

## 앞뒤 강의 연결

- 이전: **2-2 가격과 상품 구성**의 `가격·구성표`를 필요에 맞게 참조한다. 이미 설명한 내용은 짧게 회상하고 이번 강의의 판단으로 확장한다.
- 다음: **2-4 USP에 맞는 채널 계획**에서는 `고객이 있는 곳과 USP를 설명할 형식에 맞춰 채널을 고른다.` 현재 강의의 `USP·증거표` 중 필요한 내용을 다음 작업의 입력으로 넘긴다.
- 챕터가 해결하는 문제: 어떤 고객에게 무엇을 어떤 이유와 조건으로 제안할지 정한다.
- 챕터 이후 연결: 선택한 고객과 제안을 기준으로 연락 가능한 관계를 확보한다.

## 내용 근거와 직원이 읽을 출발점

- **M01 100M Offers** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/100M_PDF텍스트/100M offer.md>). 자료의 역할: 고객이 원하는 결과와 장애물을 분석하고 가치·가격·제공 범위를 설계한다.
  - 관련 개념의 위치 안내: M01 PDF 50~61; S03 SECRET 4·8·10; G003; Q011
  - 적용 경계: 정리본의 가격·보증 조언을 모든 회사에 일괄 적용하지 않는다.
- **S03 스토리 설계자** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/설계자/스토리설계자.md>). 자료의 역할: 고객의 욕구·구매 이유를 문구와 스토리로 전달한다.
  - 관련 개념의 위치 안내: M01 PDF 50~61; S03 SECRET 4·8·10; G003; Q011
  - 적용 경계: 책 제목만 보고 스토리 브랜딩 책으로 분류하지 않는다. 카피라이팅 중심이다.
- **Q011 시장/경쟁사/산업 분석 (실편)** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/콰디/011_시장_경쟁사_산업_분석_(실편).md>). 자료의 역할: 후보 나열→중요 변수→정밀 분석→가설→실행 순서로 결정을 만든다.
  - 관련 개념의 위치 안내: M01 PDF 50~61; S03 SECRET 4·8·10; G003; Q011 / Q005; Q011; S01 SECRET 5; G017
  - 적용 경계: 경쟁사 문구·상품 복제가 아닌 변수 비교와 가설 도출로 적용한다.

위 출발점과 [책의 장별 위치](../01_전체자료목록.md)를 이용해 직원은 해당 강의의 관련 자료를 전체 흐름 속에서 읽는다. 근거의 정확한 문단과 개요 주장 간 연결은 보완본에 남긴다. 리뷰와 원전을 독립된 두 증거로 세지 않는다.

## 직원에게 전달할 보완 작업

- 사용자에게 받을 자료·구체화할 대상: **고객 언어·제품 차이·검증 자료·기존 문구**.
- 각 필수 설명을 원문과 대조해 충분한 설명을 작성한다. 빠진 전제나 원문과 다른 주장이 있으면 위치와 수정안을 표시한다.
- 사례는 상황·문제·판단·실행·결과·적용 한계를 정리한다. 실제 기록이 없는 숫자나 장면은 가상 예시로 명시한다.
- 추가 자료는 어느 설명을 왜 보완하는지 기록하고 기존 자료와 충돌하면 양쪽 조건을 비교한다.
- 사용자가 최종 대본으로 옮기기 쉽도록 설명 단위마다 원천 ID·장·페이지·문단을 붙인다. 개요를 바꾸는 제안과 세부 설명 보완을 구분한다.

## 이번 개요의 미확정 사항

- 기존 점검: 초안 가능
- BPT: 내용 순서에 대한 개요이며 특정 BPT 문장·문단 대응은 미확정이다. 최종 대본 수정 단계에서 원문 구간과 논리 기능을 검토한다.

## 사용자 최종 대본 수정 시 확인

- 원문의 내용과 적용 조건이 유지되는가? 추가한 설명은 근거인가, 해석인가, 가상 예시인가?
- 문장과 문단마다 앞의 어떤 이해를 받아 다음 내용을 말하는가? 중간 전제와 답하지 않은 질문은 없는가?
- BPT 직접 대응이 어려운 부분은 어떤 기준으로 구성했는가? 확인하지 않은 패턴을 BPT 규칙이라고 쓰지 않았는가?
- 말로 읽는 문장, 화면·슬라이드 지시, 출처 메모를 구분했는가? 촬영 때 읽을 대사에 직원용 메모가 섞이지 않는가?
