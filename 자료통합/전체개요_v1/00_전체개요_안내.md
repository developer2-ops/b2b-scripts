# 66강 전체 개요 v1 — 내용 설계와 직원 전달용

2026-09-18. 현재 작업은 사용자와 함께 구체적인 개요를 만드는 단계다. 아래 66강은 검토용 내용 개요 초안이며, 확정된 촬영 대본이나 BPT 문장 대응본이 아니다.

## 작업 분담

| 단계 | 담당 | 완성할 것 |
|---|---|---|
| 구체적 개요 | 사용자 + 이 작업 | 강의별 핵심 내용·개념 관계·필수 설명·원천 출발점·범위·앞뒤 연결 |
| 자료와 내용 보완 | 직원 | 관련 자료 전체 읽기, 사용자가 추가로 준 자료 반영, 설명·근거·사례·수치·화면·빈칸 보완 |
| 최종 대본 수정 | 사용자 중심 | BPT 전개 기준과 강의 목적에 맞춰 문장·문단 연결 및 대사를 수정 |
| 촬영 | 각 강의에 표시된 담당 강사 | 최종 대본을 그대로 읽어 촬영 |

직원의 산출물은 사용자가 최종 대본을 완성할 수 있는 상세 내용과 근거다. 직원이 개요의 목적·범위·결론을 바꿔야 한다고 판단하면 바꾸는 이유와 대안을 제시한다. 현재 개요를 직원이 다시 처음부터 기획해야 하는 주제 목록 수준에 머물게 하지 않는다.

## 이 개요의 읽는 법

- 각 강의의 필수 내용을 완전한 문장으로 적었다. 번호는 설명할 내용의 관계를 보이기 위한 것이며, 모든 강의의 실제 화법을 같은 공식으로 고정하지 않는다.
- '직원이 구체화할 것'은 추가 자료·사례·실제 운영을 채우는 항목이다. 강의의 기본 주제를 직원에게 다시 정하라는 뜻이 아니다.
- 원천 위치는 상세 독해를 시작할 경로다. 전체 원문 전수 검증과 문장별 근거 카드가 모두 완성됐다는 뜻은 아니다. 원전의 주장·저자 사례·우리 적용안을 구분해 보완해야 한다.
- 앞뒤 강의의 결과물을 연결했다. 필요 선행 개념이 뒤에 등장하면 현재 강의에서 필요한 정의만 먼저 안내하고 상세 실행은 지정 강의로 넘긴다.
- 시트의 CRM '(변경안)' 표기와 비고를 유지했다. 제목 변경이나 승인 처리는 하지 않았다.
- BPT 기준 전사·패턴 카드가 미확정이므로 문장 일대일 대응은 아직 검증하지 않았다. 최종 수정 시 문장 대응 / 문단 기능 대응 / 확인된 패턴 적용 / 독립 설계를 표시한다.

## 전체 흐름

현재 상태와 판단 기준(CH00~01) → 상품과 제안(CH02) → 고객 관계·후속 메시지·구매 경로(CH03~05) → 구매 후 가치·커뮤니티·구독(CH06~08) → 유입 실행(CH09) → 위임과 통합 운영(CH10~11).

이것은 학습 순서다. 회사가 현재 유입을 멈추거나 모든 챕터의 장치를 반드시 도입해야 한다는 뜻은 아니다. 커뮤니티·구독은 적합성 판단을 포함한다. CH04에서는 메시지가 연결될 홈을 개념적으로 소개하고, CH05에서 실제 구성으로 구체화한다. CH02에서는 채널 적합성을 판단하고, CH09에서 방법을 심화한다.
