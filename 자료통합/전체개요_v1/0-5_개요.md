# 0-5. 강의 이용 방법

**촬영 담당:** 이세란

상태: 사용자 검토용 내용 개요 v1. 대본·최종 승인 전.

## 강의의 역할

영상 시청을 회사의 결정·실행·기록으로 연결한다.

## 반드시 다룰 내용과 개념 관계

1. 강의를 보는 순서와 회사에 적용하는 순서를 구분하고 전체 과정의 지도를 안내한다.
2. 강의마다 판단 또는 결과물을 남기고 다음 강의에서 이어서 사용한다.
3. 업종과 자원이 다른 사례는 조건을 비교한 뒤 적용하며 막힌 질문을 기록한다.

위 항목들은 이번 강의에서 확보할 내용의 범위다. 각 항목의 개념·이유·조건을 충분히 설명하고 서로의 관계를 드러내야 한다. 실제 대사 순서는 후속 논리 설계에서 정하며, 모든 강의를 동일한 도입·문제·해결 공식에 맞추지 않는다.

## 수강생이 남길 결과물

수강·실행·질문 방식

## 다룰 범위와 넘길 범위

운영 시간·과제 제출·피드백 방식은 사용자가 제공한 실제 운영안만 반영한다.

## 앞뒤 강의 연결

- 이전: **0-4 마케팅적으로 생각하기**의 `기존 판단·새 질문 비교표`를 필요에 맞게 참조한다. 이미 설명한 내용은 짧게 회상하고 이번 강의의 판단으로 확장한다.
- 다음: **0-6 회사 유형·규모 진단**에서는 `규모·역할·채널 의존을 확인하고 자기 회사의 출발점을 정한다.` 현재 강의의 `수강·실행·질문 방식` 중 필요한 내용을 다음 작업의 입력으로 넘긴다.
- 챕터가 해결하는 문제: 과정의 목적과 자기 회사의 출발 조건을 이해한다.
- 챕터 이후 연결: 학습 목표·회사 조건·자산 관점을 가지고 현재 상태 진단으로 넘어간다.

## 내용 근거와 직원이 읽을 출발점

- **G009 (야사지언)조언도 멍청하게 들으면 인생 조땜** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/구피디/009_(야사지언)조언도_멍청하게_들으면_인생_조땜.md>). 자료의 역할: 내 상황과 경험이 맞는 조언인지 판단한다.
  - 관련 개념의 위치 안내: G009; G018; G019; Q004; Q010
  - 적용 경계: 조언자 배경만으로 주장의 진위를 결정하지 않는다.
- **Q004 인사이트란** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/콰디/004_인사이트란.md>). 자료의 역할: 상황·문제·생각·검증을 거쳐 실제 행동으로 이어져야 한다.
  - 관련 개념의 위치 안내: G009; G018; G019; Q004; Q010
  - 적용 경계: 일반 동기부여로 축약하지 않고 실행 기록과 연결한다.
- **Q010 도망친 곳에 낙원은 없다 (복리 인생, J커브)** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/콰디/010_도망친_곳에_낙원은_없다_(복리_인생,_J커브).md>). 자료의 역할: 반복 업무와 문제 해결을 나누고 시행착오를 축적한다.
  - 관련 개념의 위치 안내: M02 PDF 237~245; M03 PDF 139~150; Q002; Q010; G014; G015 / G009; G018; G019; Q004; Q010
  - 적용 경계: 저자의 J커브 설명을 정해진 기간의 성과 보장으로 쓰지 않는다.

위 출발점과 [책의 장별 위치](../01_전체자료목록.md)를 이용해 직원은 해당 강의의 관련 자료를 전체 흐름 속에서 읽는다. 근거의 정확한 문단과 개요 주장 간 연결은 보완본에 남긴다. 리뷰와 원전을 독립된 두 증거로 세지 않는다.

## 직원에게 전달할 보완 작업

- 사용자에게 받을 자료·구체화할 대상: **수강 운영 규정, 워크시트, 질문·피드백 방식**.
- 각 필수 설명을 원문과 대조해 충분한 설명을 작성한다. 빠진 전제나 원문과 다른 주장이 있으면 위치와 수정안을 표시한다.
- 사례는 상황·문제·판단·실행·결과·적용 한계를 정리한다. 실제 기록이 없는 숫자나 장면은 가상 예시로 명시한다.
- 추가 자료는 어느 설명을 왜 보완하는지 기록하고 기존 자료와 충돌하면 양쪽 조건을 비교한다.
- 사용자가 최종 대본으로 옮기기 쉽도록 설명 단위마다 원천 ID·장·페이지·문단을 붙인다. 개요를 바꾸는 제안과 세부 설명 보완을 구분한다.

## 이번 개요의 미확정 사항

- 기존 점검: 우리 과정 운영 방식은 별도 확정
- BPT: 내용 순서에 대한 개요이며 특정 BPT 문장·문단 대응은 미확정이다. 최종 대본 수정 단계에서 원문 구간과 논리 기능을 검토한다.

## 사용자 최종 대본 수정 시 확인

- 원문의 내용과 적용 조건이 유지되는가? 추가한 설명은 근거인가, 해석인가, 가상 예시인가?
- 문장과 문단마다 앞의 어떤 이해를 받아 다음 내용을 말하는가? 중간 전제와 답하지 않은 질문은 없는가?
- BPT 직접 대응이 어려운 부분은 어떤 기준으로 구성했는가? 확인하지 않은 패턴을 BPT 규칙이라고 쓰지 않았는가?
- 말로 읽는 문장, 화면·슬라이드 지시, 출처 메모를 구분했는가? 촬영 때 읽을 대사에 직원용 메모가 섞이지 않는가?
