# 0-3. 한국 온라인 마케팅 20년 압축사

**촬영 담당:** 이세란

상태: 사용자 검토용 내용 개요 v1. 대본·최종 승인 전.

## 강의의 역할

수단의 변화와 지속되는 고객·제안·측정의 원리를 구분한다.

## 반드시 다룰 내용과 개념 관계

1. 시대별 채널을 나열하기보다 고객의 발견·비교·구매 경로가 어떻게 변했는지 설명한다.
2. 접점이 바뀔 때 기존의 성과가 그대로 이어지지 않는 이유를 플랫폼 의존과 연결한다.
3. 수단 변화와 별개로 고객·제안·측정·고객 관계를 이해해야 한다는 과제까지 정리한다.

위 항목들은 이번 강의에서 확보할 내용의 범위다. 각 항목의 개념·이유·조건을 충분히 설명하고 서로의 관계를 드러내야 한다. 실제 대사 순서는 후속 논리 설계에서 정하며, 모든 강의를 동일한 도입·문제·해결 공식에 맞추지 않는다.

## 수강생이 남길 결과물

마케팅 변화 연표

## 다룰 범위와 넘길 범위

한국 20년 연표는 현재 네 자료만으로 확정하지 않는다. 도구 사용법은 제외한다.

## 앞뒤 강의 연결

- 이전: **0-2 사장이 첫 번째 마케터다**의 `대표 판단·실행 역할표`를 필요에 맞게 참조한다. 이미 설명한 내용은 짧게 회상하고 이번 강의의 판단으로 확장한다.
- 다음: **0-4 마케팅적으로 생각하기**에서는 `만드는 사람의 관점에서 고객이 선택하는 이유를 묻는 관점으로 이동한다.` 현재 강의의 `마케팅 변화 연표` 중 필요한 내용을 다음 작업의 입력으로 넘긴다.
- 챕터가 해결하는 문제: 과정의 목적과 자기 회사의 출발 조건을 이해한다.
- 챕터 이후 연결: 학습 목표·회사 조건·자산 관점을 가지고 현재 상태 진단으로 넘어간다.

## 직원에게 전달할 보완 작업

- 사용자에게 받을 자료·구체화할 대상: **연도별 검증 가능한 사건·플랫폼 자료와 강사의 당시 경험**.
- 각 필수 설명을 원문과 대조해 충분한 설명을 작성한다. 빠진 전제나 원문과 다른 주장이 있으면 위치와 수정안을 표시한다.
- 사례는 상황·문제·판단·실행·결과·적용 한계를 정리한다. 실제 기록이 없는 숫자나 장면은 가상 예시로 명시한다.
- 추가 자료는 어느 설명을 왜 보완하는지 기록하고 기존 자료와 충돌하면 양쪽 조건을 비교한다.
- 사용자가 최종 대본으로 옮기기 쉽도록 설명 단위마다 원천 ID·장·페이지·문단을 붙인다. 개요를 바꾸는 제안과 세부 설명 보완을 구분한다.
