# 8-4. 월구독 운영 구조와 손익

**촬영 담당:** 권기동

상태: 사용자 검토용 내용 개요 v1. 대본·최종 승인 전.

## 강의의 역할

제공 범위·인력·비용·유지기간을 함께 계산한다.

## 반드시 다룰 내용과 개념 관계

1. 회원 수뿐 아니라 제공량·인력·원가·지원 비용을 함께 계산한다.
2. 신규 가입과 해지가 동시에 일어나는 운영 상황을 고려한다.
3. 서비스 품질을 유지할 수용량과 담당·반복 업무를 정한다.

위 항목들은 이번 강의에서 확보할 내용의 범위다. 각 항목의 개념·이유·조건을 충분히 설명하고 서로의 관계를 드러내야 한다. 실제 대사 순서는 후속 논리 설계에서 정하며, 모든 강의를 동일한 도입·문제·해결 공식에 맞추지 않는다.

## 수강생이 남길 결과물

구독 운영·손익표

## 다룰 범위와 넘길 범위

단순 월매출을 확정 이익으로 계산하지 않는다.

## 앞뒤 강의 연결

- 이전: **8-3 기존 상품에서 월구독으로 연결하기**의 `첫 구매→구독 경로`를 필요에 맞게 참조한다. 이미 설명한 내용은 짧게 회상하고 이번 강의의 판단으로 확장한다.
- 다음: **8-5 해지와 윈백**에서는 `해지 이유와 미사용 원인을 분리하고 개선·복귀 제안을 만든다.` 현재 강의의 `구독 운영·손익표` 중 필요한 내용을 다음 작업의 입력으로 넘긴다.
- 챕터가 해결하는 문제: 지속적인 고객 문제와 제공 능력에 맞는 반복매출 구조를 판단한다.
- 챕터 이후 연결: 고객을 받을 제안과 후속 가치 구조를 바탕으로 유입 방법을 구체화한다.

## 내용 근거와 직원이 읽을 출발점

- **M03 100M Money Models** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/100M_PDF텍스트/100M money model.md>). 자료의 역할: 유입·업셀·다운셀·지속 오퍼를 구매 순서로 배치해 초기 회수와 고객가치를 설계한다.
  - 관련 개념의 위치 안내: M02 PDF 130~140; M03 PDF 10~17; Q009 / M03 PDF 116~137; S01 SECRET 3; G007; Q006
  - 적용 경계: 오퍼 유형을 전부 쓰는 것이 목표가 아니다. 고객 필요와 제공 원가를 함께 본다.
- **G011 직원 채용과 기용(지속적 업데이트 예정)** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/구피디/011_직원_채용과_기용(지속적_업데이트_예정).md>). 자료의 역할: 사업 단계에 따라 첫 채용·반복 업무·관리 역할을 구분한다.
  - 관련 개념의 위치 안내: M02 PDF 181~199; G004; G011; Q003; Q008
  - 적용 경계: 저자 단계론을 획일적인 인원·매출 기준으로 쓰지 않는다.

위 출발점과 [책의 장별 위치](../01_전체자료목록.md)를 이용해 직원은 해당 강의의 관련 자료를 전체 흐름 속에서 읽는다. 근거의 정확한 문단과 개요 주장 간 연결은 보완본에 남긴다. 리뷰와 원전을 독립된 두 증거로 세지 않는다.

## 직원에게 전달할 보완 작업

- 사용자에게 받을 자료·구체화할 대상: **월별 가입·해지·이용량·업무 시간·원가**.
- 각 필수 설명을 원문과 대조해 충분한 설명을 작성한다. 빠진 전제나 원문과 다른 주장이 있으면 위치와 수정안을 표시한다.
- 사례는 상황·문제·판단·실행·결과·적용 한계를 정리한다. 실제 기록이 없는 숫자나 장면은 가상 예시로 명시한다.
- 추가 자료는 어느 설명을 왜 보완하는지 기록하고 기존 자료와 충돌하면 양쪽 조건을 비교한다.
- 사용자가 최종 대본으로 옮기기 쉽도록 설명 단위마다 원천 ID·장·페이지·문단을 붙인다. 개요를 바꾸는 제안과 세부 설명 보완을 구분한다.

## 이번 개요의 미확정 사항

- 기존 점검: 우리 운영 가정 명시
- BPT: 내용 순서에 대한 개요이며 특정 BPT 문장·문단 대응은 미확정이다. 최종 대본 수정 단계에서 원문 구간과 논리 기능을 검토한다.

## 사용자 최종 대본 수정 시 확인

- 원문의 내용과 적용 조건이 유지되는가? 추가한 설명은 근거인가, 해석인가, 가상 예시인가?
- 문장과 문단마다 앞의 어떤 이해를 받아 다음 내용을 말하는가? 중간 전제와 답하지 않은 질문은 없는가?
- BPT 직접 대응이 어려운 부분은 어떤 기준으로 구성했는가? 확인하지 않은 패턴을 BPT 규칙이라고 쓰지 않았는가?
- 말로 읽는 문장, 화면·슬라이드 지시, 출처 메모를 구분했는가? 촬영 때 읽을 대사에 직원용 메모가 섞이지 않는가?
