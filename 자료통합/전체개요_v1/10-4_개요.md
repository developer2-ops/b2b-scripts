# 10-4. 마케팅 직원 채용

**촬영 담당:** 이세란

상태: 사용자 검토용 내용 개요 v1. 대본·최종 승인 전.

## 강의의 역할

필요한 결과·역량·교육·측정 방식으로 채용 기준을 만든다.

## 반드시 다룰 내용과 개념 관계

1. 뽑을 사람의 직함보다 맡길 결과물과 책임 범위를 먼저 정의한다.
2. 필요 역량을 실제 작업과 검수 기준으로 확인한다.
3. 입사 후 자료·교육·피드백·평가 흐름을 설계한다.

위 항목들은 이번 강의에서 확보할 내용의 범위다. 각 항목의 개념·이유·조건을 충분히 설명하고 서로의 관계를 드러내야 한다. 실제 대사 순서는 후속 논리 설계에서 정하며, 모든 강의를 동일한 도입·문제·해결 공식에 맞추지 않는다.

## 수강생이 남길 결과물

직무·평가·온보딩표

## 다룰 범위와 넘길 범위

학력·연봉을 능력의 고정 대리 지표로 사용하지 않는다.

## 앞뒤 강의 연결

- 이전: **10-3 AI 활용**의 `AI 업무·검수표`를 필요에 맞게 참조한다. 이미 설명한 내용은 짧게 회상하고 이번 강의의 판단으로 확장한다.
- 다음: **10-5 외주·대행사 관리**에서는 `대행 결과의 판단 기준과 데이터 접근·인수인계를 정한다.` 현재 강의의 `직무·평가·온보딩표` 중 필요한 내용을 다음 작업의 입력으로 넘긴다.
- 챕터가 해결하는 문제: 실행을 나누면서 판단 기준과 자산이 회사에 남게 한다.
- 챕터 이후 연결: 분리한 역할과 결과물을 한 운영 체계로 연결한다.

## 직원에게 전달할 보완 작업

- 사용자에게 받을 자료·구체화할 대상: **직무기술서·실무 과제·온보딩·평가표**.
- 각 필수 설명을 원문과 대조해 충분한 설명을 작성한다. 빠진 전제나 원문과 다른 주장이 있으면 위치와 수정안을 표시한다.
- 사례는 상황·문제·판단·실행·결과·적용 한계를 정리한다. 실제 기록이 없는 숫자나 장면은 가상 예시로 명시한다.
- 추가 자료는 어느 설명을 왜 보완하는지 기록하고 기존 자료와 충돌하면 양쪽 조건을 비교한다.
- 사용자가 최종 대본으로 옮기기 쉽도록 설명 단위마다 원천 ID·장·페이지·문단을 붙인다. 개요를 바꾸는 제안과 세부 설명 보완을 구분한다.

## 이번 개요의 미확정 사항

- 기존 점검: 초안 가능
- BPT: 내용 순서에 대한 개요이며 특정 BPT 문장·문단 대응은 미확정이다. 최종 대본 수정 단계에서 원문 구간과 논리 기능을 검토한다.

## 사용자 최종 대본 수정 시 확인

- 원문의 내용과 적용 조건이 유지되는가? 추가한 설명은 근거인가, 해석인가, 가상 예시인가?
- 문장과 문단마다 앞의 어떤 이해를 받아 다음 내용을 말하는가? 중간 전제와 답하지 않은 질문은 없는가?
- BPT 직접 대응이 어려운 부분은 어떤 기준으로 구성했는가? 확인하지 않은 패턴을 BPT 규칙이라고 쓰지 않았는가?
- 말로 읽는 문장, 화면·슬라이드 지시, 출처 메모를 구분했는가? 촬영 때 읽을 대사에 직원용 메모가 섞이지 않는가?
