# 10-2. 회사 규모별 운영 방식

**촬영 담당:** 권기동

상태: 사용자 검토용 내용 개요 v1. 대본·최종 승인 전.

## 강의의 역할

현재 회사 규모와 병목에 맞춰 역할을 나눈다.

## 반드시 다룰 내용과 개념 관계

1. 현재 인력·업무량·의사결정 병목을 기준으로 운영 역할을 나눈다.
2. 규모가 커질 때 개인 실행·팀 관리·조직 간 조율의 비중이 달라지는 이유를 설명한다.
3. 이번 규모에서 먼저 분리할 역할과 아직 묶어도 되는 일을 정한다.

위 항목들은 이번 강의에서 확보할 내용의 범위다. 각 항목의 개념·이유·조건을 충분히 설명하고 서로의 관계를 드러내야 한다. 실제 대사 순서는 후속 논리 설계에서 정하며, 모든 강의를 동일한 도입·문제·해결 공식에 맞추지 않는다.

## 수강생이 남길 결과물

규모별 역할표

## 다룰 범위와 넘길 범위

칼럼의 매출 구간·채용 등급을 업종 공통 기준으로 사용하지 않는다.

## 앞뒤 강의 연결

- 이전: **10-1 직접 실행부터 위임까지**의 `위임 순서표`를 필요에 맞게 참조한다. 이미 설명한 내용은 짧게 회상하고 이번 강의의 판단으로 확장한다.
- 다음: **10-3 AI 활용**에서는 `AI에 맡길 입력·출력과 사람이 검수할 기준을 정한다.` 현재 강의의 `규모별 역할표` 중 필요한 내용을 다음 작업의 입력으로 넘긴다.
- 챕터가 해결하는 문제: 실행을 나누면서 판단 기준과 자산이 회사에 남게 한다.
- 챕터 이후 연결: 분리한 역할과 결과물을 한 운영 체계로 연결한다.

## 내용 근거와 직원이 읽을 출발점

- **Q003 10억 ~ 1000억 매출 규모별로 필요한 능력 (커머스)** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/콰디/003_10억_~_1000억_매출_규모별로_필요한_능력_(커머스).md>). 자료의 역할: 초기 시장 선택에서 콘텐츠·광고 실험, 이후 조직 운영으로 초점이 변한다.
  - 관련 개념의 위치 안내: M02 PDF 181~199; G004; G011; Q003; Q008
  - 적용 경계: 10억·100억·300억의 기준은 저자 커머스 경험의 구분이다.
- **G011 직원 채용과 기용(지속적 업데이트 예정)** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/구피디/011_직원_채용과_기용(지속적_업데이트_예정).md>). 자료의 역할: 사업 단계에 따라 첫 채용·반복 업무·관리 역할을 구분한다.
  - 관련 개념의 위치 안내: M02 PDF 181~199; G004; G011; Q003; Q008
  - 적용 경계: 저자 단계론을 획일적인 인원·매출 기준으로 쓰지 않는다.
- **G014 영천일십백 - 단계별로 돈을 올인해야 하는곳 찝어줌** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/구피디/014_영천일십백_-_단계별로_돈을_올인해야_하는곳_찝어줌.md>). 자료의 역할: 현재 단계에 맞춰 매출·채용·복제·관리에 자원을 배분한다.
  - 관련 개념의 위치 안내: M02 PDF 237~245; M03 PDF 139~150; Q002; Q010; G014; G015
  - 적용 경계: 규모별 처방의 성립 조건을 기록한다.

위 출발점과 [책의 장별 위치](../01_전체자료목록.md)를 이용해 직원은 해당 강의의 관련 자료를 전체 흐름 속에서 읽는다. 근거의 정확한 문단과 개요 주장 간 연결은 보완본에 남긴다. 리뷰와 원전을 독립된 두 증거로 세지 않는다.

## 직원에게 전달할 보완 작업

- 사용자에게 받을 자료·구체화할 대상: **조직도·업무량·대표 병목·실제 규모별 사례**.
- 각 필수 설명을 원문과 대조해 충분한 설명을 작성한다. 빠진 전제나 원문과 다른 주장이 있으면 위치와 수정안을 표시한다.
- 사례는 상황·문제·판단·실행·결과·적용 한계를 정리한다. 실제 기록이 없는 숫자나 장면은 가상 예시로 명시한다.
- 추가 자료는 어느 설명을 왜 보완하는지 기록하고 기존 자료와 충돌하면 양쪽 조건을 비교한다.
- 사용자가 최종 대본으로 옮기기 쉽도록 설명 단위마다 원천 ID·장·페이지·문단을 붙인다. 개요를 바꾸는 제안과 세부 설명 보완을 구분한다.

## 이번 개요의 미확정 사항

- 기존 점검: 매출 구간을 보편 기준으로 고정하지 않음
- BPT: 내용 순서에 대한 개요이며 특정 BPT 문장·문단 대응은 미확정이다. 최종 대본 수정 단계에서 원문 구간과 논리 기능을 검토한다.

## 사용자 최종 대본 수정 시 확인

- 원문의 내용과 적용 조건이 유지되는가? 추가한 설명은 근거인가, 해석인가, 가상 예시인가?
- 문장과 문단마다 앞의 어떤 이해를 받아 다음 내용을 말하는가? 중간 전제와 답하지 않은 질문은 없는가?
- BPT 직접 대응이 어려운 부분은 어떤 기준으로 구성했는가? 확인하지 않은 패턴을 BPT 규칙이라고 쓰지 않았는가?
- 말로 읽는 문장, 화면·슬라이드 지시, 출처 메모를 구분했는가? 촬영 때 읽을 대사에 직원용 메모가 섞이지 않는가?
