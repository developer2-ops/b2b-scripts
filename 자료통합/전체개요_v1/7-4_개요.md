# 7-4. 소개 프로그램과 연결하기

**촬영 담당:** 이세란

상태: 사용자 검토용 내용 개요 v1. 대본·최종 승인 전.

## 강의의 역할

성과를 경험한 고객의 소개를 커뮤니티 흐름에 연결한다.

## 반드시 다룰 내용과 개념 관계

1. 커뮤니티 참여의 만족과 외부 사람에게 추천할 이유를 구분한다.
2. 추천 대상·초대 시점·신규 회원이 받을 가치를 명확히 한다.
3. 초대 후 첫 경험과 기존 회원 경험이 함께 유지되도록 운영한다.

위 항목들은 이번 강의에서 확보할 내용의 범위다. 각 항목의 개념·이유·조건을 충분히 설명하고 서로의 관계를 드러내야 한다. 실제 대사 순서는 후속 논리 설계에서 정하며, 모든 강의를 동일한 도입·문제·해결 공식에 맞추지 않는다.

## 수강생이 남길 결과물

소개 동선

## 다룰 범위와 넘길 범위

일반 소개 프로그램은 6-4를 재사용하고 커뮤니티 맥락의 차이만 심화한다.

## 앞뒤 강의 연결

- 이전: **7-3 후기와 수익인증 플라이휠**의 `후기·사례 수집표`를 필요에 맞게 참조한다. 이미 설명한 내용은 짧게 회상하고 이번 강의의 판단으로 확장한다.
- 다음: **7-5 운영 위임과 측정**에서는 `담당자·운영 반복 업무·측정 기준을 분리한다.` 현재 강의의 `소개 동선` 중 필요한 내용을 다음 작업의 입력으로 넘긴다.
- 챕터가 해결하는 문제: 필요한 회사에 한해 커뮤니티의 고객 가치·참여·운영 조건을 설계한다.
- 챕터 이후 연결: 커뮤니티 유무와 별개로 지속 가치에 대한 반복 결제 가능성을 검토한다.

- **M02 100M Leads** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/100M_PDF텍스트/100M leads.md>). 자료의 역할: 참여 리드를 얻는 네 가지 방법과 고객·직원·대행사·제휴를 통한 확장을 다룬다.
  - 관련 개념의 위치 안내: M02 PDF 159~180; G008
  - 적용 경계: 리드와 참여 리드를 구분한다. 책의 네 가지 방법과 우리 강의의 네 가지 분류는 동일하지 않다.
- **Q006 유료 구독, 할만할까? _ 유료 구독자 차별점** — [본문](</Users/seranlee/B2B강의대본/자료통합/_원문/콰디/006_유료_구독,_할만할까_유료_구독자_차별점.md>). 자료의 역할: 무료·유료 글, 질문 답변, 대화 공간, 개별 지원의 차이를 설명한다.
  - 관련 개념의 위치 안내: M03 PDF 139~147의 커뮤니티 사례; Q006; G002; G008

위 출발점과 [책의 장별 위치](../01_전체자료목록.md)를 이용해 직원은 해당 강의의 관련 자료를 전체 흐름 속에서 읽는다. 근거의 정확한 문단과 개요 주장 간 연결은 보완본에 남긴다. 리뷰와 원전을 독립된 두 증거로 세지 않는다.

## 직원에게 전달할 보완 작업

- 사용자에게 받을 자료·구체화할 대상: **회원 초대·온보딩·추천 보상 실제 사례**.
- 각 필수 설명을 원문과 대조해 충분한 설명을 작성한다. 빠진 전제나 원문과 다른 주장이 있으면 위치와 수정안을 표시한다.
- 사례는 상황·문제·판단·실행·결과·적용 한계를 정리한다. 실제 기록이 없는 숫자나 장면은 가상 예시로 명시한다.
- 추가 자료는 어느 설명을 왜 보완하는지 기록하고 기존 자료와 충돌하면 양쪽 조건을 비교한다.
- 사용자가 최종 대본으로 옮기기 쉽도록 설명 단위마다 원천 ID·장·페이지·문단을 붙인다. 개요를 바꾸는 제안과 세부 설명 보완을 구분한다.

## 이번 개요의 미확정 사항

- 기존 점검: 초안 가능
- BPT: 내용 순서에 대한 개요이며 특정 BPT 문장·문단 대응은 미확정이다. 최종 대본 수정 단계에서 원문 구간과 논리 기능을 검토한다.

## 사용자 최종 대본 수정 시 확인

- 원문의 내용과 적용 조건이 유지되는가? 추가한 설명은 근거인가, 해석인가, 가상 예시인가?
- 문장과 문단마다 앞의 어떤 이해를 받아 다음 내용을 말하는가? 중간 전제와 답하지 않은 질문은 없는가?
- BPT 직접 대응이 어려운 부분은 어떤 기준으로 구성했는가? 확인하지 않은 패턴을 BPT 규칙이라고 쓰지 않았는가?
- 말로 읽는 문장, 화면·슬라이드 지시, 출처 메모를 구분했는가? 촬영 때 읽을 대사에 직원용 메모가 섞이지 않는가?
