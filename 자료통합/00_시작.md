# B2B 강의 대본 — 자료 통합

2026-09-18 정리. **내용은 설계자 + 100M 시리즈 + 구피디 + 콰디를 조합하고, 문장별 전개는 BPT를 참고한다.** 제목은 지정 시트, 제목의 이유와 수강생 변화는 rizz-hub B2B 기획을 따른다.

## 현재 작업

**사용자와 함께 강의별 구체적인 내용 개요를 만드는 단계.** [66강 개요 v1](전체개요_v1/00_전체개요_안내.md)을 작성했다. 직원은 관련 자료 전체 독해와 설명·사례 보완을 맡고, 사용자가 최종 논리·대사를 수정해 촬영한다. BPT 문장 대응과 촬영 대본은 아직 미완료다.

## 추가된 설계 기준

[전체 개요와 논리 설계 기준](07_전체개요와논리설계기준.md): 전체 개요를 먼저 잡는 순서, 원문에서 강의 주장으로 옮기는 과정, BPT 대응이 어려울 때의 대안, 문장·문단·강의 사이의 연결 검토.

## 네 묶음의 역할

- **설계자 4권:** 고객이 발견→관심→신뢰→구매→후속 구매로 움직이는 전체 구조와 메시지.
- **100M 3권:** 무엇을 어떻게 제안할지, 고객을 어떻게 확보할지, 다음 거래와 반복매출을 어떻게 설계할지.
- **구피디 21편:** 해외 원리를 해석한 설명, 광고·상품·조직 운영 경험. 책 리뷰 부분은 원전과 중복 표시.
- **콰디 11편:** 커머스 시장 분석·소재 실험·손익·시행착오·위임의 구체적 적용.

하나의 강의에는 중심 원리와 필요한 보완 자료만 넣는다. 네 묶음을 매번 동일한 비율로 섞지 않는다. 원문과 우리 종합 해석을 구분한다.

## 현재 상태

- 자료 확보·유형 구분·원문 보존·본문 추출·초기 개념 분류·66강 배정: 완료.
- 100M은 GPD의 한국어 PDF에서 Offers 139쪽, Leads 246쪽, Money Models 154쪽 전체 텍스트를 추출했다. 번역 정확성 전수 대조는 미실시.
- 책·칼럼 모든 문장의 사실 검증, 도표·외부 링크 전수 열람: 미실시.
- 강의별 자료 배정: **검토용 초안**. 시트 제목과 비고는 원문 유지.
- BPT 기준 전사 확정·강의별 문장 대응·촬영 대본: 아직 미작성.
- 원본 파일·구글 시트·외부 DB는 수정하지 않았다.

## 보관 방식

`_원문/`에는 기존 전문·기획·시트의 복사본, 100M PDF의 전체 추출 텍스트, 기존 요약·워크북을 보관한다. `_관리/`에는 원천 ID·원본 경로·해시·추출 및 대조 결과가 있다. 설계자 이미지·원본 PDF 일부는 원래 폴더에 연결되므로 다른 컴퓨터로 옮길 때는 원본 자산도 필요하다.

## 현재 검토 순서

66강 개요 v1에서 각 강의의 필수 설명·자료·범위·앞뒤 연결을 구체화한다. 직원의 상세 내용 보완과 사용자의 최종 대본 수정은 이후 단계다. 현재 3개 핵심 항목은 검토의 출발점이며, 필요한 하위 설명을 충분히 보완한 뒤 직원에게 전달한다.
