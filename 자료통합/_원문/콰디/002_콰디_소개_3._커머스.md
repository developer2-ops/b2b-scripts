커머스를 훨~~~~씬 궁금해하실 것 같아서 커머스부터 작성!


사실 커머스판에는

1) 저보다 훨씬 더 오래있었고

2) 저보다 훨씬 더 큰 볼륨으로

3) 저보다 훨씬 더 잘 하는 사람들이 많을거라서

내가 이런 글을 쓸 자격이 있나? 하는 생각들이 많이 들지만


그래도 내가 잘하는

1) 데이터 정리 / 분석

2) 짱 빠른 실행 무한반복

3) 이미 시행착오 겪은 지인들의 레버리지

3가지를 통해서 짱 짱 짱 빠르게 성과내고 있는 과정이 도움이 되지 않을까 싶습니다


![image.png](https://ndqabxgwlsqmelahegyg.supabase.co/storage/v1/object/public/newsletters/1785753412556-image.png)

작년 10월에 런칭한 브랜드인데

10월 : 300

11월 : 3000

12월 : 4.3억

01월 : 7.2억

나름 빠르게 유의미한 성과를 내고 있는 것 같아 관련한 사항들을 기재할 예정!


커머스 시장을 파보면서 느낀건

1) 진짜 공평한 게임이다

- 진입장벽이 높지 않음

초기비용이 많이 발생하는 타 사업대비 현저하게 적은 자본으로 시작할 수 있음

- 실력만 있으면 '투입 시간과 관계없이' 매출 만들 수 있음

물론 실력이 있기 위해서, 실력을 기르는 시간이 필요하겠지만

실력만 좋다면 바로 매출 100억, 300억도 할 수 있음

(실제로 런칭 1달만에 일매출 1억 찍은 지인도 있음)

2) 시장이 크다

3) 변수가 너~~~~무 많다

트렌드, 광고, 경쟁사 등 변수가 매일 튀어나온다!

매일이 문제 투성이에, 얼만큼 문제 해결을 잘 오래 하냐 싸움!

달리지 않으면 넘어지는 자전거 같다

이게 핵심이라고 보는데, 너무 많은 변수를 얼만큼 통제가능하냐가 실력인것같다

1단계는 어떻게든 매출내는것, 2단계는 내가 하던것을 위임하는것, 3단계는 내가 만든 시스템이 굴러가는것

4단계는 확장 -> 1000억

대부분은 1단계도 어려워하지만

비슷한 나이인데 4단계까지 다 해놓고 1000억 넘게 하는 사람들도 있고

몇백억정도 매출을 하는 사람들은 진짜 많다

커머스만큼 젊은 나이에 몇백억 매출 하는 사람들 없을듯


부동산을 하면서 얻은 분석/정리 병을 기반으로

![image.png](https://ndqabxgwlsqmelahegyg.supabase.co/storage/v1/object/public/newsletters/1785754073230-image.png)

1) 어떤 시장이 있는지

2) 잘 하고 있는 곳이 어디인지

3) 해당 업체는 어떻게 잘 하는지 - 잘 하는 것의 변수는 무엇이 있는지

4) 나는 어떻게 잘할것인지

를 무한반복 하고 있는 중인데

이 과정을 계속 기록하고 공유해보고자 합니다!


참고로 저는 1) 지속가능한 2) 확장가능한 이 제 비지니스 철학이라서

1) 이미 저렇게 한 지인들이 존재함 - 준거집단 진짜 중요, 옆에서 하니까 어라 하면 될 수 있나보다 + 나 더 열시히 해야겠다

2) 커머스는 정말 자아 하나도 없이 돈 벌고 싶어서 하는 사업 -> 어디까지 내가 갈 수 있는지 궁금함. 증명하고싶음

달성하고 나서 제가 만족할 수도 있고, 더 하고 싶을 수도 있고, 브랜딩을 제대로 하고 싶을 수도 있고
