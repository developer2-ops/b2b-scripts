사장이 알아야 하는 것은 AI가 어떻게 작동하는지의 원리입니다. 3가지인데요. 

<a id="32e84687-79ee-8098-b745-f5295aee2c4a"></a>

첫번째, 한 번 물어보고 끝나는 자판기가 아니라는 것. AI는 처음에 80점짜리 나오면 잘 된 겁니다. 

<a id="32e84687-79ee-8039-92a1-daea2bba70be"></a>

두번째, 거기서 피드백 주고 수정하고 다시 돌리는 이터레이션이 필요하다는 것. 

<a id="32e84687-79ee-80da-8dd9-ea80cc29c8d7"></a>

세번째, AI는 아이디어를 100개 뽑는 발산은 잘하지만, 지금 우리 회사에서 당장 쓸 것 하나를 고르는 수렴은 사람이 해야 한다는 것. 

<a id="32e84687-79ee-80c6-b082-c4a4b0d5e206"></a>

이 세 가지를 모르면 직원이 AI로 뭘 하는지 볼 수가 없습니다.

<a id="32e84687-79ee-80f8-8368-e1d651888a0f"></a>


사장이 시켜야 하는 것은 구조 설계입니다. AI한테 아무 지시나 던지면 30분 후에 완전히 다른 걸 하고 있습니다. 신입 직원한테 매뉴얼 없이 일 시키면 어떻게 되는지 아시잖아요. AI도 똑같습니다. 뭘 해야 하는지, 어디까지 해야 하는지, 다 했으면 뭘 확인해야 하는지, 이 구조를 사전에 잡아줘야 합니다.

<a id="32e84687-79ee-8034-b53f-cc83e3142b31"></a>

<a id="32e84687-79ee-803a-a8b7-c55dc515baae"></a>

그래서 구체적으로 어떻게 하냐. 하는걸 보여드릴게요. 일단 제가 해보니깐 일적으로 시키기에는 클로드가 제일 낫습니다. 그리고 클로드 코드 가셔서 폴더 하나를 새로 만드시구요. 가장 기초중에 기초 CLAUDE.md라는 파일을 하나 만들거예요.  어렵게 생각하실 필요 없습니다. 텍스트 파일 하나입니다. 거기에 내가 쓸 필요도 없어요. 그냥 [claude.md](http://claude.md) 파일 만들건데하고 사이트 링크를 주세요. 저처럼 유튜브나 다른게 있다면 그것도 다 주세요. 회사 브로슈어 이런것도 좋습니다. 여기서 만약 사내관련 내용을 하고 싶으시면 조직도를 주셔도 됩니다. 저는 일단 사이트 링크를 주고 그에 관해 claude.md 파일을 만들어달라고 했습니다.  이걸 만들어두면 AI가 매번 새로 시작하는 게 아니라 이 매뉴얼을 기반으로 일합니다. 그럼 우리 회사가 뭔지를 ai 가 인지를 하고 있어요. 뭘 해야 하는지, 어디까지 해야 하는지, 다 했으면 뭘 확인해야 하는지, 이 구조가 생기는 겁니다.이게 시작입니다. 대표인 내가 직접 코딩을 할 필요가 없습니다. 우리 회사에서 AI한테 시키고 싶은 일의 기준을 글로 정리하는 것, 그게 전부입니다.
