고객을 어떻게 데리고 올건지, 또 각 과정에서 어떻게 고객을 나눠서 리타겟을 할건지, 고객이 우리 병원을 알고 실제 예약까지 어떻게 가치를 높일건지, 그래서 그 고객들을 내원까지 노쇼하지 않고 어떻게 이끌건지 이후에 내원후에도 재방문까지 고객을 나눠서 어떤식으로 부담스럽지 않게 할건지 이런거를 짠거예요. 이게 나오면 각 과정에서 유튜브를 보게 할수도 있고, 인스타로 연락할수도 있고 또 카톡이나 문자를 보낼수도 있죠. 

<a id="20084687-79ee-80eb-818e-f73eb716cfd9"></a>

<a id="20084687-79ee-80c4-81dc-e3d60d61f585"></a>

그리고 가장 좋은건 뭐냐? 객단가를 높이려고 하지 않았지만 높아집니다. 왜냐면 애초에 고객이 내 가게 문을 들어오기 전에 리타겟이 되어서 가치가 높아진 상태로 방문하는거니까요. 

<a id="20084687-79ee-80e4-a570-cb4469dd74f9"></a>

<a id="20084687-79ee-80b6-aff6-eb66eba06817"></a>

사실 여기서도 훨씬 정교하게 하면 추가 지불 의사가 있는지를 아예 처음부터 확인할수 있는 방법도 있는데 이것까지 이야기 하면 너무 길어지니깐 일단 이번 강의는 여기까지 하겠습니다. 

<a id="20084687-79ee-805b-8077-d8e4c08837a6"></a>

<a id="20084687-79ee-80bb-a657-cd15dcf02e57"></a>

<a id="20084687-79ee-80d9-98b9-f3a8649956f2"></a>

<a id="20084687-79ee-80c7-bdef-e8c20ea64bb5"></a>

오늘은 여기까지 해서 업종을 나눠서 객단가 높이는 방법을 배워봤는데요. 사실 객단가 높이는건 간단합니다. 고객 인지 가치를 높이고, 고객을 붙잡고 있으면 됩니다. 바로 그 힘을 만드는게 마케팅이예요. 

<a id="20084687-79ee-80de-b32f-f7a9a1ee2eb7"></a>

<a id="20084687-79ee-803e-88a3-c980c5b38863"></a>

마케팅은 이번달 돈 벌려고 하는게 아닙니다. 이번달 당장 돈이 필요하다면 ‘광고’를하세요. 엘리베이터에 있는 모니터에 내 가게 영상을 돈내고 부탁하거나 유튜버 인플루언서 블로거를 불러서 내가게 관련한 영상을 올려달라고 하는것들 이런건 다 광고입니다. 그리고 이런건 휘발되죠. 고객이 인지하는 가치를 높이기도 어렵습니다. 

<a id="20084687-79ee-803e-b7d7-ed0c55d604e2"></a>

<a id="20084687-79ee-8033-b7b0-cf7a5a86e092"></a>

<a id="20084687-79ee-8079-9d0c-c9be3507613b"></a>

만약 이것들에 지쳤다면 심화 시리즈를 봐보세요. 보통 스스로 지쳤다고 이야기 하지만 막상 실제 이야기를 들어보면 그냥 지금 당장의 매출에 집중하는 분들이 많습니다. 그러면 계속 매출은 오르겠지만 순수익 비율은 계속 떨어지죠. 근데 그때는 이미 늦습니다. 다시 개선하려면 완전히 바꿔야 하는데 그럼 지금 매출이 떨어질까봐 불안하거든요. 그렇게 되기 전에 꼭 심화강의를 다 보셨으면 좋겠습니다. 저도 이걸 몰라서 망한거였거든요.
