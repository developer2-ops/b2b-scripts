1. 성공전략 : 레드오션에서 블루오션을 찾아낸 3가지 포인트

<a id="2da84687-79ee-8066-a199-f9fa8f259aa5"></a>

- 전략 1. '금은방'이 아닌 '브랜드'를 팔다:

<a id="2da84687-79ee-80d7-9e1c-e62cee9d4717"></a>

◦ 기존 순금 시장은 '금은방' 외에 연상되는 브랜드가 없는 거대하지만 세분화되지 않은 시장이었음.

<a id="2da84687-79ee-80f6-bd8e-f749ebe5cc3f"></a>

◦ 단순한 현물 거래를 넘어 '신뢰'할 수 있는 프리미엄 브랜드로 포지셔닝하여 고객의 심리적 장벽을 허묾.

<a id="2da84687-79ee-804a-96ae-d9cbb09635ea"></a>

- 전략 2. 디자인의 혁신 (Old → Young):

<a id="2da84687-79ee-803b-b0a2-cf350a57f293"></a>

◦ 순금 특유의 무른 성질 때문에 디자인이 투박했던 한계를 극복하기 위해 아버지의 제조 노하우와 본인의 디자인 감각을 결합.

<a id="2da84687-79ee-8028-b775-cbedf4bfc77e"></a>

◦ 2030 세대도 패션 아이템으로 선호할 만한 감각적인 제품을 제안.

<a id="2da84687-79ee-8046-b0c4-d3a18ce0b291"></a>

- 전략 3. 데이터가 증명한 기획 상품 '콩알금':

<a id="2da84687-79ee-80ea-b896-eb5a7b575267"></a>

◦ 중국 MZ세대의 유행을 포착해 한국형 '10만 원대 금 재테크' 문화를 만듦.

<a id="2da84687-79ee-8092-99ec-c471d42e2adc"></a>

◦ 고가(150만 원 이상) 제품 위주에서 벗어나 누구나 쉽게 접근할 수 있는 '미끼 상품'으로 온라인 시장을 장악

<a id="2da84687-79ee-8046-9124-ee0376cc18da"></a>

<a id="2da84687-79ee-8026-9cee-de799b783d90"></a>

전환점: 홈쇼핑 의존에서 자생적 브랜드로의 독립

<a id="2da84687-79ee-8057-8d9f-df5a0c33b054"></a>

과거 홈쇼핑 매출 100억을 달성했으나, 유통 플랫폼과 MD에게 휘둘리는 구조의 위험성을 깨달음.

<a id="2da84687-79ee-8086-bd8d-e0070d5fe881"></a>

- 직원들의 생계와 회사의 미래를 위해 자사몰 중심의 브랜드 사업으로 전향하여 현재 매출의 70%를 브랜드에서 창출

1. 마케팅 솔루션

<a id="2da84687-79ee-804d-bbf3-df69cec47417"></a>

- 문제점: 훌륭한 제품력을 가졌으나, 현재 마케팅은 퍼포먼스 광고와 자사몰 내부 인터뷰 위주로 한정됨. 유튜브 운영의 효율성과 지속성 고민.

<a id="2da84687-79ee-80f6-a17e-ebd582824ea5"></a>

- 솔루션 1. '고충' 기반의 커뮤니티 구축:

<a id="2da84687-79ee-8030-b462-f4d2c222e7a0"></a>

◦ 금은 '시세 변동'이라는 확실한 고충(Pain Point)이 있음. 주식처럼 고객들이 매일 들어와 정보를 나눌 수 있는 커뮤니티(카페 등)를 유튜브와 연계해야 함.

<a id="2da84687-79ee-8082-a186-f78e122a808f"></a>

- 솔루션 2. 타겟팅의 확장 (경쟁 상대를 바꿔라):

<a id="2da84687-79ee-80e6-85e3-ca663a7e2dc5"></a>

◦ 금 투자 수요는 KRX와 경쟁하지만, 자산 은닉과 증여를 원하는 고액 자산가의 니즈는 다름.

<a id="2da84687-79ee-80c4-9c10-f6fd0a2d0f90"></a>

◦ 명품 가방(샤넬, 루이비통)과 경쟁한다는 관점에서 '현물 자산의 안전성'이라는 코어 메시지를 강화해야 함.

<a id="2da84687-79ee-80ef-b15f-e699ebbba709"></a>

- 솔루션 3. 콘텐츠 시스템화:

<a id="2da84687-79ee-80c1-9c29-d67577119e95"></a>

◦ 직접 편집하는 수고를 덜고, 당근마켓에서 은(Silver)을 팔아 트래픽을 모았던 경험처럼 고객이 저절로 모이는 '미끼 콘텐츠'와 '커뮤니티'의 결합 제안
