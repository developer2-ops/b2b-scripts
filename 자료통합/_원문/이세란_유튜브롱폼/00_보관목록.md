# 이세란 유튜브 롱폼 원문 보관·매칭

수집일: 2026-09-21 (Asia/Seoul)

이세란의 개인 스토리, 생각, 판단 이유와 설명 논리를 찾는 사용자 지정 원천이다. 원문·검색용 발췌·B2B 활용 해석을 구분한다. 인터뷰이의 경험을 이세란 본인의 경험으로 바꾸지 않는다.

## 저장·대응 범위

- 노션 원문 162페이지를 블록 JSON과 읽기용 Markdown으로 보관했다. 자영업 루트·하위 53페이지, 마케팅1타의 콘텐츠 관리·고정참조 20페이지, 연결 작업 89페이지다. 작업 템플릿·기획·질문지·편집 메모를 포함하므로 이 숫자가 완성 대본 개수는 아니다.
- 공개 동영상 목록 48개: 업로드 링크로 연결 14개(대본 10개·인터뷰 자료 4개), 제목·본문 기준 대응 27개, 내용상 대응 후보 7개. 후보는 최종 영상과 추가 대조가 필요하다.
- 업로드 링크 연결은 노션 관리 기록의 영상 ID 일치다. 대본과 최종 영상의 문장별 일치나 인터뷰 전체 전사를 뜻하지 않는다.
- 페이지 본문의 자식 블록 및 작업 관계를 따라 수집했다. 현재 미확보 본문 블록 0개. 원문 JSON과 읽기용 변환본을 함께 보관했다.
- 자영업 미디어 ZIP은 생성이 끝났고 약 3.6GB 파일을 브라우저에서 다운로드 중이다. 프로젝트 폴더 복사·압축 검증은 미완료다. 읽기용 대본의 원격 이미지·영상·첨부 링크를 로컬 저장 완료로 간주하지 않는다. 첫 번째 노션 연결 작업의 미디어도 원문 링크를 보존했다.
