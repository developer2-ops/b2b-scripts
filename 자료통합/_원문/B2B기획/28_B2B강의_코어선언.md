## 1. 이 강의가 주려는 경험 — "길이 보이는 순간"

- 목표는 지식 전달이 아니라 **가슴이 뻥 뚫리고 마음이 두근거리는 경험**. 1강을 보고 떠오르는 게 너무 많아서 2강으로 못 넘어가는 강의.
- 근거는 사란님 자신의 10년: 사업하는 내내 불안하고 답답했던 이유는 능력이 없어서가 아니라 **아무도 길을 보여준 적이 없어서**.
- 커리큘럼의 SA·DA·변천사 같은 제목은 관리용 리스트일 뿐. 173강 전부의 실제 내용은 하나 — **길을 보여주는 것.** 각 강은 원본 문서에서 사란님이 실제로 두근거렸던 것만 추린 결과물.
- 사업을 제대로 하는 사람일수록 이 길이 보이는 순간 반응한다 — 타겟 검증 기준.

## 2. 핵심 신념 — 마케팅은 세일즈 기술이 아니라 대표의 사고 OS

마케팅을 제대로 알면 회사 운영의 모든 문제가 풀린다. 여기서 마케팅 = 고객 세일즈가 아니라 **"상대가 원하는 것을 읽고, 내 것을 그에 맞게 설계해서, 선택받게 만드는 사고법"** 전체.

| 장면 | 마케팅으로 다시 읽으면 |
|---|---|
| 채용 | 인재라는 고객에게 회사를 파는 것 — 채용공고가 랜딩페이지 |
| 급여·보상 제도 | 직원 대상 오퍼 설계 — 잔류·성과가 나오게 만드는 가격 정책 |
| 인사관리·조직문화 | 직원의 "재구매"(계속 다니고 싶게) 설계 |
| 상품 기획 | 만들고 파는 게 아니라 팔릴 것을 만드는 것 |
| 가격 결정 | 원가가 아니라 인식의 설계 |
| 업체 미팅·협상 | 내 포지셔닝과 증거 제시 — B2B 세일즈 퍼널 |
| 투자·대출 | 금융기관이라는 고객에게 하는 IR — 신용도 결국 노출·설득·재구매 |
| CS·컴플레인 | 재구매 마케팅이자 입소문 소재 관리 |
| 대표 개인 브랜딩 | 위 전부의 신용 담보 — 나 자신을 마케팅해야 사람이 붙는다 |

→ **"본질 강의가 곧 마케팅 강의"다.** 별도의 본질 강의가 빠진 게 아니라, 대표가 마케팅적으로 생각하는 법 자체가 본질이고, 그걸 가르쳐야 진짜 그 회사 매출이 오른다.

## 3. 시장 차별화 — 서울대 선생님이 아니라 "못했다가 잘하게 된 선생님"

- 지금 B2B 강의 시장의 공식: 레퍼런스로 조지기("나 얼마 벌었다") = 학원의 서울대 선생님 모델. 후킹은 되지만 공부 못하는 학생에게 서울대 선생님은 못 가르친다.
- 우리의 포지션: **실패했다가 잘하게 된 선생님.** 학부모(대표들)는 그런 선생님이 있다는 걸 알기만 하면 무조건 온다.
- 실체적 근거: 수많은 실패·회복 경험 → **자영업부터 브랜드사까지 매출액 구간별로 막힌 지점을 진단하는 능력.** "얼마 벌었다"로는 복제 불가능한 자산.

## 4. 두 가지 리스크와 해소 구조

### 리스크 ① 레퍼런스 열위 — 나보다 잘난 대표들도 이 강의를 듣는다

- 해소 A: 싸움의 종목을 바꾼다. 우리 상품은 자랑이 아니라 **진단력** — 서울대 자랑과 경쟁하지 않는다.
- 해소 B: 4개월 내 세일즈 성과에는 후킹용 권위가 필요 → **IP 결합.** 역할 분담: IP(예: 박치은 대표) = 동기부여·후킹·오프라인 / RIZZ = 코어(길)·온라인 173강. IP 이야기의 결론이 "결국 온라인을 잘해서 됐다"이므로 IP가 자연스럽게 온라인 강의로 랜딩시킨다.
- 해소 C: 업체 실사례는 동의 문제 → 실명 자랑 대신 **익명화·패턴화**("매출 구간별 문제 지도")로 동의 리스크 없이 진단력을 증명.

### 리스크 ② 세일즈 vs 코어의 긴장 — 세일즈는 놓치기 싫지만 코어는 안 판다

- 해소: 구조로 분리. 세일즈 장치(IP·오프라인·업종별 적용 세션) = 퍼널 앞단 / 코어(마케팅적 사고의 길) = 온라인 본체. 업종별 디테일은 강의 내 예시 + **오프라인 업종별 적용 세션**으로 커버 — 코어 희석 없음.

## 5. 성장 논리 — 1000명은 1000명이 아니다

- B2B 강의의 성패는 광고가 아니라 **입소문**.
- 정말 길을 보여주면 수강생은 반드시 친구 한 명을 데려온다. 첫 1000명은 매출이 아니라 **씨앗**.
- 최종 목표 포지션: **"창업하기 전에 제발 이것부터 보라"는 강의.** 이게 되는 순간 카테고리를 소유한다.
