# CH00. 강의 목표

> 기존 v6의 논리와 7강 순서는 바꾸지 않는다.
>
> `강의의 약속 → 대표의 역할 → 마케팅 역사 → 마케팅 공부법 → 동기부여 → 회사 상태 진단 → 단리·복리 계산`

## 0-1. 이 강의의 약속 — 매출 강의가 아니라 영업이익 강의

- 이 강의의 목표는 영업이익 30% 높이기
- 영업이익을 높이는 방법은 두 가지
  - 매출을 올린다
  - 비용과 비효율을 줄인다
- 매출을 올리려면 세 숫자를 본다
  - 트래픽
  - 전환율
  - 리텐션
- 이 강의는 세 숫자를 한 번 올리고 끝내는 강의가 아니다
- 실행한 마케팅이 다음 달에도 남도록 시스템화하는 강의다

여기서는 트래픽·전환·리텐션의 세부 방법을 가르치지 않는다. 뒤의 유입·전환·재구매 강의에서 배우게 될 전체 지도를 먼저 보여준다.

### 이 강의를 듣는 방법

- 강의를 처음부터 끝까지 보는 것이 목표가 아니다
- 각 강의를 자기 회사 숫자에 대입해야 한다
- 대표는 방향을 결정하고 실행담당자는 실제로 적용한다
- 커뮤니티에는 질문만 올리는 것이 아니라 실행 결과와 숫자를 올린다
- 강의 혜택과 제공 자료를 어떻게 사용하는지 안내한다

```text
왜 매출이 아니라 영업이익인가
→ 영업이익을 바꾸는 두 방향
→ 매출을 바꾸는 세 숫자
→ 이 숫자를 회사의 시스템으로 남기는 것이 복리 마케팅
→ 이 강의를 적용하는 방법
```

## 0-2. 사장이 첫 번째 마케터다

- 기술자가 돈을 잘 버는 시대는 끝났다
- 만들어 주는 기술의 단가는 점점 내려간다
- 반대로 잘 팔리게 만드는 판단의 가치는 높아진다
- 대표가 광고와 콘텐츠를 모두 직접 해야 한다는 뜻은 아니다
- 대표는 다음 네 가지를 판단해야 한다
  - 누구에게 팔 것인가
  - 무엇을 팔 것인가
  - 왜 우리를 선택해야 하는가
  - 어떤 숫자로 잘되고 있는지 판단할 것인가
- 실행은 직원·AI·외주에게 맡길 수 있다
- 하지만 판단까지 맡기면 계정과 데이터만 남의 회사에 쌓인다

### 규모 4단계 연결

```text
규모 1: 대표가 직접 실행하고 AI를 사용
규모 2: 대표가 방향을 정하고 담당자가 실행
규모 3: 대표가 공통 지표로 팀을 운영
규모 4: 대표가 내부와 외부의 역할·예산·데이터를 통제
```

## 0-3. 한국 온라인 마케팅 20년 압축사

- 기술이 바뀔 때마다 실행 수단의 단가는 내려갔다
- 카페·블로그·SNS·광고·AI가 등장해도 대표가 해야 하는 판단은 사라지지 않았다
- 수단을 먼저 배우면 유행을 따라가게 된다
- 고객·상품·숫자를 먼저 이해하면 수단이 바뀌어도 판단할 수 있다

이 강의는 `기술자 시대가 끝났다`는 말을 역사적 흐름으로 증명하는 역할을 한다.

## 0-4. 마케팅 공부법 — 쓰레기 조언 거르는 법

| 기술적 생각 | 마케팅적 생각 |
| --- | --- |
| 무엇을 더 잘 만들까 | 고객은 무엇을 선택할까 |
| 기능이 얼마나 좋은가 | 고객이 어떤 차이를 인식하는가 |
| 경쟁사보다 무엇이 더 많은가 | 고객이 기억할 한 가지가 무엇인가 |
| 어떤 채널이 유행하는가 | 우리 고객은 어디서 어떤 이유로 움직이는가 |
| 광고를 어떻게 돌릴까 | 지금 상품·전환·리텐션 중 어디가 막혔는가 |
| 일을 누가 대신해 줄까 | 판단 기준과 데이터가 회사에 남는가 |

### 마케팅 조언을 볼 때 확인할 기준

1. 이 조언은 어떤 업종과 규모에 해당하는가?
2. 매출이 아니라 공헌이익까지 좋아지는가?
3. 일회성 성과인가, 회사에 자산이 남는가?
4. 성공 사례만 있고 실패 조건은 빠져 있지 않은가?
5. 우리 회사의 현재 병목과 관계가 있는가?

## 0-5. 동기부여 — 100억의 전제조건과 좆됨의 재해석

기존 내용과 위치를 유지한다.

> 지금까지 사업이 어려웠던 이유는 대표에게 능력이 없어서가 아니라, 회사 전체 마케팅 지도를 보지 못한 채 매번 한 가지 기술만 해결하려 했기 때문이다.

이 강의의 역할은 방법을 더 알려주는 것이 아니라, 다음 진단을 피하지 않게 만드는 것이다.

## 0-6. 우리 회사는 여섯 유형 중 어디, 규모 4단계 중 어디

- 우리 회사가 어떤 유형인지 선택한다
- 현재 규모와 실행 구조를 확인한다
- 대표 개인에게 묶여 있는지 확인한다
- 플랫폼·광고·대행사에 의존하고 있는지 확인한다
- 트래픽·전환·리텐션 중 어느 숫자를 모르는지 확인한다
- 회사에 남은 자산을 확인한다
  - 검색 자리
  - 고객 DB
  - 데이터
  - 매뉴얼
  - 사람

상세 퍼널 작성과 손익 입력은 다음 강의인 0-7에서 수행한다. 여기서는 현재 위치만 판단한다.

## 0-7. 단리·복리 계산 — 숫자 3개로 우리 마케팅비 진단

- 월 마케팅비
- 광고를 모두 끄면 다음 달에 남는 매출 비율
- 현재 회사가 가진 복리 자산
- 트래픽·전환·리텐션의 현재 숫자
- 모르는 숫자와 실제 0을 구분한다
- 여러 문제가 나왔을 때 첫 번째 순서를 결정한다

### 이 강의의 결과

```text
현재 단리로 쓰는 마케팅비
→ 이미 복리로 전환된 부분
→ 가장 먼저 손댈 병목
→ 3개월 동안 옮길 목표
→ 다음에 들어야 할 강의 블록
```

영업이익 30%는 실제 회사 숫자에 대입한다.

```text
현재 영업이익
→ 트래픽·전환율·리텐션 중 바꿀 숫자
→ 필요한 변화량
→ 30% 개선이 가능한지 계산
→ 불가능하면 회사에 맞는 현실적 목표로 수정
```

## CH00에서 뒤로 넘길 내용

- 상품과 USP 만드는 법 → `② 상품·시장·고객·USP`
- 트래픽·전환·리텐션의 구체적인 방법 → `③ 방법 이해`
- 채널별 실행법 → `④ 수단 모듈`
- 직원·AI·외주에게 위임하는 법 → `⑤ 조직 운영`
- 전체 시스템화 → `⑥ 회사 전체 마케팅 시스템`

CH00에서는 이 내용들이 왜 필요한지만 보여주고, 실제 방법은 원래 위치에서 가르친다.
