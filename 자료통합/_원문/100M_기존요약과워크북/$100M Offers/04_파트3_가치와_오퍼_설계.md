# 파트 3. 가치와 오퍼 설계

## 1. 가치 공식

책의 중심 공식은 다음과 같다.

> 가치 = (꿈의 결과 × 달성 가능성에 대한 인식) ÷ (시간 지연 × 노력과 희생에 대한 인식)

수학적으로 정확한 계산식이라기보다 오퍼를 진단하는 사고 도구다.

### 1.1 꿈의 결과를 키운다

고객이 궁극적으로 원하는 상태다. 기능이나 수단이 아니라 도착한 뒤의 경험을 말해야 한다.

- 헬스장 이용권이 아니라 원하는 몸과 자신감
- 광고 관리가 아니라 안정적인 신규 고객과 매출
- 강의 수강이 아니라 실제 업무 성과와 지위 변화

꿈의 결과는 종종 타인에게 어떻게 보이는가와 연결된다. 고객이 원하는 존중, 지위, 안정, 사랑, 능력의 증명을 읽어야 한다.

### 1.2 달성 가능성에 대한 인식을 높인다

고객은 결과뿐 아니라 `나도 실제로 성공할 수 있는가`를 산다.

이를 높이는 요소는 다음과 같다.

- 유사 고객의 사례
- 반복 가능한 과정
- 실적과 숙련도
- 구체적인 단계와 진척 기준
- 고객의 위험을 줄이는 보장
- 실패 원인을 미리 제거하는 지원

### 1.3 시간 지연을 줄인다

구매 후 핵심 가치를 느끼기까지 걸리는 시간이 짧을수록 가치가 커진다. 최종 결과가 오래 걸리더라도 초기에 작은 승리를 설계할 수 있다.

- 첫 주 안에 첫 문의 받기
- 가입 당일 진단 결과 받기
- 첫 세션에서 즉시 사용할 결과물 얻기
- 장기 과정 중 명확한 중간 성과 확인하기

고객은 장기 결과를 사지만, 과정 중의 빠른 승리 때문에 계속 참여한다.

### 1.4 노력과 희생을 줄인다

고객이 해야 할 일, 배워야 할 것, 포기해야 할 것, 감수해야 할 불편을 줄인다.

- 직접 제작 대신 양식과 자동화 도구 제공
- 복잡한 선택 대신 추천안 제공
- 긴 교육 대신 바로 쓰는 점검표 제공
- 고객이 하던 일을 함께 하거나 대신 수행

기능을 더하는 것만이 가치 향상이 아니다. 대기 불안, 선택 피로, 복잡성 같은 심리적 비용을 줄이는 해결책도 강력하다.

## 2. 발산 사고

오퍼를 만들 때 처음 떠오른 하나의 해결책에 바로 수렴하지 않는다. 같은 문제를 해결하는 여러 방법을 먼저 만든 뒤 선택한다.

책의 벽돌 연습은 크기, 재질, 모양, 사용 환경을 바꾸면 같은 벽돌도 전혀 다른 가치를 만들 수 있음을 보여준다. 오퍼 역시 개인 대 집단, 실시간 대 녹화, 직접 수행 대 대행, 느린 지원 대 즉시 지원 등 조건을 바꾸면 새로운 구성이 나온다.

## 3. 그랜드슬램 오퍼 제작 5단계

### 1단계. 꿈의 결과를 정한다

고객이 구매하는 최종 목적지를 한 문장으로 적는다. 수단이 아니라 결과여야 한다.

나쁜 예: 주 3회 운동 프로그램

좋은 예: 6주 동안 일상생활을 유지하면서 원하는 체형에 가까워지기

### 2단계. 고객이 겪을 모든 문제를 나열한다

고객 여정을 시간순으로 따라가며 구매 전, 사용 중, 결과 달성 후의 장애물을 적는다. 각 단계에서 가치 공식의 네 요소를 질문한다.

- 이 결과가 내게 충분히 가치 있는가?
- 나에게도 실제로 효과가 있을까?
- 너무 오래 걸리지 않을까?
- 너무 어렵고 불편하거나 희생이 크지 않을까?

문제가 많이 나온다는 것은 나쁜 일이 아니다. 해결하고 가치를 만들 기회가 많다는 뜻이다.

### 3단계. 모든 문제를 해결책 문장으로 바꾼다

각 장애물을 `어떻게 하면 …할 수 있는가` 형태로 뒤집는다.

- 건강식 구매가 복잡하다 → 누구나 빠르고 쉽게 건강식을 고르는 방법
- 시간이 없다 → 5분 안에 준비하는 방법
- 여행 중 유지할 수 없다 → 출장과 여행에서도 지속하는 방법
- 나에게 맞지 않을까 걱정된다 → 상황별 조정 기준과 개인화 절차

한 가지 작은 반대 이유가 전체 구매를 막을 수 있으므로 가능한 장애물을 빠짐없이 다룬다.

### 4단계. 해결책의 전달 수단을 발산한다

각 해결책을 실제로 전달할 방법을 여러 개 만든다.

#### 전달 설계 육면체

- 관심 수준: 일대일, 소그룹, 일대다
- 고객 수행 수준: 직접 하기, 함께 하기, 대신 해주기
- 매체: 대면, 전화, 문자, 전자우편, 화상, 채팅
- 소비 형식: 실시간, 녹화 영상, 음성, 문서
- 응답 속도: 즉시, 한 시간 안, 하루 안, 평일만, 상시
- 극단 질문: 가격이 열 배라면 무엇을 주겠는가? 가격이 10분의 1이어도 더 큰 가치를 주려면 어떻게 하겠는가?

이 단계에서는 비용 걱정으로 아이디어를 미리 죽이지 않는다.

### 5단계. 다듬고 쌓는다

모든 전달 수단을 고객가치와 사업 비용으로 평가한다.

| 고객가치 | 사업 비용 | 판단 |
|---|---|---|
| 높음 | 낮음 | 반드시 포함할 핵심 자산 |
| 높음 | 높음 | 가격과 차별화에 따라 선별 포함 |
| 낮음 | 낮음 | 제거 우선순위가 높음 |
| 낮음 | 높음 | 즉시 제거 |

가장 좋은 자산은 처음 만드는 데는 시간이 들지만 추가 고객에게 제공하는 비용은 거의 없는 것이다. 계산기, 양식, 점검표, 자동화, 녹화 안내, 사례 데이터베이스 등이 여기에 해당한다.

남은 해결책을 묶어 하나의 완성된 가치 묶음으로 만든다. 각 항목은 고객의 특정 문제를 해결해야 하며, 이름과 기대효과를 붙여 이해하기 쉽게 제시한다.

## 4. 최종 오퍼가 해야 하는 세 가지 일

1. 고객이 예상하는 문제를 일부가 아니라 전체적으로 해결한다.
2. 판매자가 자신의 제안이 독특하다고 확신하게 만든다.
3. 고객이 주변의 흔한 상품과 직접 비교하기 어렵게 만든다.

## 5. 파트 실행 체크리스트

- [ ] 고객의 꿈의 결과를 한 문장으로 적었다.
- [ ] 고객 여정을 구매 전부터 결과 달성 후까지 시간순으로 펼쳤다.
- [ ] 각 단계의 시간, 노력, 불확실성, 가치 의문을 모두 적었다.
- [ ] 모든 문제를 해결책 문장으로 바꿨다.
- [ ] 각 해결책마다 여러 전달 방식을 만들었다.
- [ ] 고비용·저가치 항목을 제거했다.
- [ ] 저비용·고가치 자산을 우선 배치했다.
- [ ] 전체 묶음이 경쟁 상품과 직접 비교하기 어려운지 확인했다.

## 파트 요약

가치를 높이는 가장 강력한 방법은 큰 약속만 만드는 것이 아니다. 고객이 결과를 더 확실하게 믿고, 더 빨리 첫 성과를 느끼며, 더 적은 노력으로 끝까지 실행하도록 만드는 것이다. 그 과정에서 고객의 모든 장애물을 해결책과 전달 자산으로 바꾼다.
