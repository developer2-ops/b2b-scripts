# 《100M 머니 모델》 파트별 정리

## 문서 성격

- 원본: `/Users/seranlee/Downloads/$100M Money Models.pdf`
- 저자: 알렉스 호르모지
- 원본 분량: 파일 189쪽, 본문 인쇄면 175쪽
- 정리 방식: 스캔된 영문 원본을 문자 인식한 뒤 실제 파트와 장 구조에 맞춰 한국어로 요약
- 목적: 오퍼의 배열을 통해 고객 획득비를 회수하고 장기 고객가치를 높이는 구조를 이해하고 설계하기 위함

이 폴더는 원문 전체를 옮긴 번역본이 아니다. 핵심 개념, 오퍼 유형, 적용 순서, 계산 기준, 위험 요소를 재구성한 학습용 요약본이다.

책에 등장하는 매출, 전환율, 환불률, 광고 수익률은 저자와 사례 기업의 결과다. 일반적인 성과를 보장하지 않는다. 경품, 무료 체험, 자동 결제, 환불, 위약금, 가격 표시를 실제 사업에 적용할 때는 현재 지역의 법률과 결제망·광고 플랫폼 정책을 별도로 확인해야 한다.

## 이 책의 전체 흐름

> 유입 오퍼로 고객과 초기 현금을 얻는다 → 상향판매로 더 많은 문제를 해결하며 30일 이익을 높인다 → 거절한 고객에게 하향판매를 제시한다 → 지속결제로 장기 고객가치를 쌓는다.

## 빠른 읽기 순서

- 전체 개념만 빠르게: `01 → 02 → 07`
- 신규 고객 확보가 문제라면: `03 → 07 → 08`
- 객단가를 높이고 싶다면: `04 → 05 → 08`
- 구독과 반복 매출이 필요하다면: `06 → 07 → 08`
