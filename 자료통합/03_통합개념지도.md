# 통합 개념 지도

여러 자료를 한 강의에 조합할 때 쓰는 작업용 개념 사전이다. 아래 설명은 원전을 종합한 적용 제안이며 개별 저자의 문장 인용이 아니다.

흐름: **대표의 판단 → 진단 → 고객·시장·상품 → DB → 메시지·전환 → 구매 후 관계 → 반복매출 → 유입 확장 → 위임 → 회사 운영**. 실제 강의 순서는 시트의 66강을 유지한다.
