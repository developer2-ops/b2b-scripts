# 2008년 5억 원의 물가 환산

확인일: 2026-09-18. 강의 본문에서 2025년 기준임을 명시한다. 2026년 현재 월의 환산값으로 표현하지 않는다.

- 출처: World Bank WDI, Korea Rep., FP.CPI.TOTL, 소비자물가지수(2010=100).
- URL: https://api.worldbank.org/v2/country/KOR/indicator/FP.CPI.TOTL?date=2008:2025&format=json
- API 갱신일: 2026-07-13. 해당 응답에서 최신 연간 관측은 2025년.
- 직접 확인값: 2008년 94.538685077841, 2025년 135.002199769989.
- 계산: 500,000,000 × 135.002199769989 ÷ 94.538685077841 ≈ 714,005,064원.
- 본문 반올림: 약 7억 1천만 원. 소비자물가에 따른 구매력 비교이며 임금 상승률·투자수익·부동산 가격 환산이 아니다.
- 앞의 평균 연봉 약 20명분 비교와 기준을 구분하기 위해 “물가 상승을 반영하면”을 명시.
- 피델리아 실적은 2008년 발표자료이며 실적 집계기간은 불명확하다. 기존 본문과 동일하게 2008년을 비교 기준으로 둔다.

사용자 요청: “여기에 뒤로 요즘으로 따지면 약 얼마 정도인지 말해줘.” 선택 문장 바로 뒤에 한 문장만 추가하고 기존 본문은 보존. 새 공통 작성 기준은 없어 기존 금액·연도·단위 규칙 적용. 독립 수치 보완, BPT 직접 대응 미확정·검증 미완료.
